# FPS Project Agent Rules

- Use TypeScript strict mode.
- Do not rewrite unrelated files.
- Do not add dependencies without explaining why.
- Keep gameplay logic separate from rendering.
- Use interfaces for weapons, enemies, damage, and events.
- Run the project after every feature.
- Report modified files and test results.
- Preserve existing behavior unless the task explicitly changes it.
- Prefer small, reversible changes.
- Never replace working systems with placeholder logic without permission.
